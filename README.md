# kb-imoons 个人知识库

基于 Cloudflare Pages + GitHub 托管的个人知识库，收录前端开发、后端开发、DevOps、AI & ML、工具推荐、银河麒麟、Linux命令 等分类的技术文章。

## 访问地址

🔗 **https://kb-imoons.pages.dev/**

## 分类

| 分类 | 说明 |
|------|------|
| 🎨 前端开发 | CSS Grid/Flexbox 等布局技术 |
| ⚙️ 后端开发 | Python、异步编程等后端技术 |
| 🚀 DevOps | Docker、Linux 命令、CI/CD |
| 🤖 AI & ML | LLM 应用开发、大模型工具 |
| 🔧 工具推荐 | 提升效率的开发工具 |
| 🦊 银河麒麟 | 银河麒麟操作系统相关内容 |
| 💻 Linux命令 | Linux 常用命令与实战 |

## 技术栈

- **前端**: 原生 HTML/CSS/JS，无框架依赖
- **后端**: 无后端，数据全在 `data/knowledge.json`
- **托管**: Cloudflare Pages（自动部署）
- **源码**: GitHub（版本管理与协作）

## 文章格式

每篇文章包含：
- `id` - 唯一标识
- `title` - 标题
- `desc` - 简短描述
- `tags` - 标签数组
- `content` - HTML 格式正文
- `level` - 难度等级（入门/中级/高级）
- `views` - 阅读量
- `date` - 发布日期
